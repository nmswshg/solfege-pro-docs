Release History

New features, improvements, and fixes in each version

This page lists user-facing changes. Some minor releases are grouped together.

v1.3.2 (August 2026)

  • Revamped first-run experience (the intro quiz now answers with degree names, plus an optional screen tour after the quiz)
  • Settings decluttered — the in-app guide list is now grouped under a single "How to Use" entry
  • Improved stability and internal measurement accuracy

v1.3.1 (July 2026)

  • Added in-app "How to Use" spotlight tutorials to every training
  • Added Lock Screen widgets and iOS 18 Control Center controls
  • Rhythm training (tap mode) no longer interrupts background music playback
  • Fixed minor-key mis-grading in Chord Progression plus many sight-reading and plan-settings bugs

v1.3.0 (July 2026)

  • Completely reworked the practice recommendation engine
  • More varied Chord Progression questions and corrected grading inconsistencies
  • Added off-beat insights to the rhythm results screen
  • Added an optional sight-reading mode that also grades note values

v1.2.5 (July 2026)

  • Reworked the free allowance into a shared pool of 10 sessions across all trainings
  • Added persistent X / Instagram / Save share buttons to the results screen
  • Added sharing for practice plans
  • Fixed an issue where PRO sometimes failed to activate after purchase

v1.2.3 (July 2026)

  • Added social share cards (personal bests, streaks, and daily results, in 4 languages)
  • Long-press widget editing now lets you choose which practice plan to display
  • Fully refreshed widget layouts (completion states, weekly calendar, VoiceOver support)
  • Fixed the stuck keyboard when renaming plans, repeated daily notifications, and more

v1.2.2 (June 2026)

  • Added Home Screen widgets (Small / Medium / Large) and Live Activity for practice plans
  • Each setting's "?" button now opens help with a direct link to the detailed manual
  • Chord and Scale Recognition now vary the root note per question for broader practice
  • Strengthened VoiceOver support and fixed a lingering-microphone issue

v1.2.1 (May 2026)

  • Added the Rhythm Sight Reading training
  • Fixed "Next Practice" becoming unresponsive in practice plans
  • Fixed the plan screen freezing after the subscription screen

v1.2 (April 2026)

  • Introduced Practice Plans — build your own daily menu, start from templates, get notification reminders, and track progress with badges
  • Refreshed the results screen (grades and comparison data)
  • Reworked onboarding into a two-screen quiz

v1.1.5–v1.1.8 (March–April 2026)

  • Made every training free to try (full switch to free access)
  • Added rhythm diagnosis & prescription
  • Added cohort comparison against other users

v1.1.4 (March 2026)

  • Added five new I/IV/V four-chord patterns to Chord Progression training
  • Beginner mode now serves a wider variety of questions

v1.1.3 (March 2026)

  • Fixed auto-advance not following settings in Scale, Chord, and Progression trainings
  • Fixed answer buttons becoming unresponsive in weak-point mode
  • Optimized auto-advance timing

v1.1.1–v1.1.2 (January–March 2026)

  • Fixed tap-mode latency compensation with Bluetooth headphones
  • Introduced per-device latency settings (speaker / wired / Bluetooth)
  • Calibration results now apply only to the current device category

v1.1.0 (January 2026)

  • Added Chord Recognition training (12 chord types by ear)
  • Added Scale Recognition training (8 scales by ear)
  • Added Chord Progression training (typical progressions such as II-V-I)
  • Introduced a shared piano sound source for ear training

v1.0.0 (December 2025)

  • Initial release
  • Shipped with four trainings: Interval, Rhythm (tap/clap), Sight Reading, and Fretboard
  • Included metronome and tuner tools
