Politique de confidentialité

Les informations traitées par Solfege PRO et leur finalité.

Principes

Solfege PRO ne comporte aucune création de compte. L'app ne collecte pas d'informations personnelles telles que votre nom ou votre adresse e-mail.

Informations collectées

Données d'utilisation

Pour améliorer l'app, nous collectons des événements d'utilisation anonymes via Google Firebase Analytics : écrans et entraînements utilisés, statistiques de pratique (précision, etc.), ainsi que le modèle d'appareil, la version du système, la version de l'app et la langue. Ces données ne permettent pas de vous identifier personnellement.

Rapports de plantage

Pour corriger les dysfonctionnements, nous collectons des rapports de plantage via Firebase Crashlytics.

Micro

Le micro sert uniquement à détecter les claquements de mains et les taps dans les entraînements rythmiques. Le son est traité sur votre appareil — il n'est jamais enregistré ni envoyé à un serveur.

Achats

Les paiements sont traités par Apple. Nous n'avons jamais accès à vos données de paiement, comme les numéros de carte bancaire.

Formulaire de contact

Le contenu envoyé via le formulaire de contact (y compris les coordonnées que vous choisissez d'indiquer) n'est utilisé que pour traiter votre demande.

Suppression des données et questions

Pour toute demande de suppression de données ou question, utilisez le formulaire de contact ci-dessous. Supprimer l'app efface les données stockées sur votre appareil. Les identifiants Firebase sont réinitialisés à la réinstallation de l'app.

→ Ouvrir le formulaire de contact (Google Forms)

Services tiers

  • Google Firebase — voir Confidentialité et sécurité dans Firebase
  • Apple (distribution via l'App Store et traitement des paiements)

Modifications

En cas de modification de cette politique, la version à jour sera publiée sur cette page. Date d'entrée en vigueur : 3 août 2026.

Éditeur

Édité par l'équipe Solfege PRO. Contactez-nous via le formulaire ci-dessus.
