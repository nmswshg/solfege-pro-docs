サポート

お問い合わせ・購入の復元・サブスクリプションの解約・返金・動作環境のご案内

お問い合わせ

バグ報告・機能リクエスト・その他のご質問は、すべて以下のお問い合わせフォームで受け付けています。

→ お問い合わせフォームを開く（Google フォーム）

  • 返信の目安: 通常5営業日以内（重大な不具合は1営業日以内の返信を目標としています）
  • アプリ内の「設定 → サポート」からも同じ窓口に到達できます

購入の復元

機種変更やアプリの再インストール後は、アプリの購入画面下部にある「購入を復元」ボタンから購入内容を復元できます。購入時と同じApple IDでサインインしていれば、追加料金なしで復元できます。

サブスクリプションの解約

  1. iPhoneの「設定」アプリを開く
  2. 自分の名前をタップ
  3. 「サブスクリプション」をタップ
  4. 「ソルフェージュPRO」を選び、キャンセルする

解約後も、現在の請求期間が終了するまではご利用いただけます。

返金

返金はAppleが処理します。reportaproblem.apple.com から申請してください。返金の可否はAppleの判断で決定されます。

動作環境

iOS 17.6以降を搭載したiPhone / iPadに対応しています。
