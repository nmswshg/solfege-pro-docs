해상도에서 4-Bar 진행

왜 커리큘럼인가?

대부분의 음악 학습자는 일부 시점에서 T / SD / D (으뜸음, Sub 지배적 인, Dominant)를 통해 제공됩니다. Yet 매우 몇 곡을 듣고 즉시 "이 SD입니다, 이것은 D입니다." 이유는 간단합니다 : 라벨을 알고 듣고 두 가지 완전히 다른 기술입니다.

이 문서는 기능적인 조화의 개념적인 개요가 아닙니다 — 실제로 귀를 짓는 커리큘럼입니다. 필수 배경은 최소한입니다: 순서에 Lv1에 Lv4를 통해서 작동은 기능에 의하여 4bar 진행을 읽는 것을 가지고 갑니다.

관련 배경

개념적인 측 (T/SD/D는인 무엇이고 왜 그들은 그 방법이라고 분류됩니다)는 안으로 커버됩니다 진행 훈련은 무엇입니까?. 이 문서는 실제적인 후속입니다.

디자인 원리: 상표의 2개의 층

"T / SD / D"와 리드는 혼자 가장 학습자가 떨어지는 원인이됩니다. 라벨은 아직 의미가 없습니다. "Dominant"에 대한 답변은 단지 기호 조작이 무엇인지 알 수 없습니다 - 당신은 오른쪽 또는 잘못을 추측 할 수 있습니다, 학습 underneath없이.

이 커리큘럼 따라서 쌍 펠트 라벨 (stable / opening / 반환하려는) 기능 상표 (T/SD/D) 각 단계에. 한 번의 인식이 안정된 기능 라벨에 터치만 하면 됩니다.

제품정보 Felt 상표 초 (C의 키)
T 안정 / "나는 집" C, Am, Em
SD 열기 / 밖에서 족답 F, Dm
D 반환 / 다시 당겨 G, G7

맵핑은 고정되어 있으므로 이론 라벨은 나중에 자연스럽게 자리에 스냅됩니다. "아, 그 '환불'감은 지배적이었습니다." 다른 방법을 이동 — 이론을 먼저 — 일반적으로 스틱하지 않습니다.

왜 4개의 막대기 오른쪽 단위

기능 듣는 학습의 점은 궁극적으로 귀에 의한 실제 음악의 흐름을 따르는 것입니다. 그래서 연습 단위는 가능한 한 밀접하게 실제 노래를 닮아야한다.

4개의 막대기를 선택하는 3가지의 이유:

  1. T → SD → D → T 주기는 자연적으로 적합합니다. 4 막대기의 맞은편에 막대기 당 1개의 기능 = 16의 볼트. 충분히 개발, 기억에 충분히 짧은.
  2. 팝업 진행과 같은 단위. I-V-vi-IV, I-IV-V-I, ii-V-I-I-I-I와 같은 표준은 4bar (또는 4 초) 단위입니다. 실제 노래로 직접 지도 연습.
  3. "음악처럼 필"의 최소 단위. 단 하나 코드 또는 2 초 쌍은 교련 같이 느낍니다; 4개의 막대기 갑자기 노래의 조각 같이 소리. 그 감각은 동기 부여.

4 단계 계획

4bar 진도에 똑바로 잠그는 것은 능률적입니다. 한 번에 느꼈다. 각 Lv의 목표가 충족 될 때 다음 단계로 이동 - 고정 일정이 없습니다.

Lv 1

" 해결? 또는 여전히 가고?" — D → T 느낌 빌드

이름 *: 8/10의 정확도에서 "실행"에서 "resolved"를 말하십시오.

두 개의 코드를 재생합니다. 청취자는 간단한 이진을 답변합니다. "마지막 코드가 끝나는 것처럼 느낀다?" "Dominant"와 "으뜸음"라는 단어는이 단계에서 사용되지 않습니다.

ExampleG → C    /    D → G    /    A → D    → "해결"
ExampleC → G    /    G → D    /    D → A    → "실행"

두 패턴을 똑같게 섞는다. 내부는 D → T 및 T → D이지만 라벨은 다음 레벨까지 기다릴 수 있습니다. 이 수준을 건너 뛰고 나중에 대답은 기호 조작이됩니다.

Lv 2

"Stable" vs "수신을 돌려" - T vs D

이름 *: 으뜸음 후에 1개의 코드 권리는 8/10 정확도에 D (환불하는)에서 T (정격한)를 말합니다.

중요한 규칙: 고립에 있는 코드를 선물하지 마십시오. 자신의 G를 재생하고 "이 D는?"는 의미없는 - G는 상황에 따라 T 또는 D입니다. 항상 토닉을 가진 닻, 그 후에 시험 코드: C → G.

C의 열쇠에서, 사용: ₢ 킹, 사이트맵, 사이트맵. G와 G7을 동일한 기능으로 치료하십시오 — 학습자는 tonal 다름에 기능적인 동일성을 기록합니다.

ExampleC → G    → 안정되어 있는 → 돌려보내기 (T → D)
ExampleC → G7    → 안정되어 있는 → 돌려보내기 (T → D)
ExampleC → C    → 안정 → 안정 (T → T)

대답 UI는 "stable / Wanting to return"또는 "T / D"일 수 있습니다. 학습자의 현재 상태에 맞는 선택.

Lv 3

"Opening" 추가 - SD 소개

이름 *: 8/10 정확도의 음속 후 하나의 코드에 대해 "정상 / 오프닝 / 원하는"에서 선택.

SD는 D의 명확한 신원이 부족합니다. 그래서 그것은 그것을 가르치는 가장 효율적인 D와 대비: "환불하지 않음" - 대신 "앞으로"또는 "오픈"

C에 있는 SD 코드: ₢ 킹, 램 = SD. Lv2의 C/G/G7에 이것을 3 방법 선택하기 위하여 추가하십시오.

CompareC → F    → 안정되어 있는 → 오프닝 (T → SD)
CompareC → G    → 안정되어 있는 → 돌려보내기 (T → D)
CompareC → Dm    → 안정되어 있는 → 오프닝 (T → SD)

F와 Dm 소리는 다른 그러나 SD 기능을 공유합니다. 당신이 추적하는 것은 기능, 색깔 아닙니다. 초보자는 종종 "F가 밝고 Dm은 어두운"-이 수준에서, 그 구별은 소음입니다.

Lv 4

4-Bar 진행 Labeling — 실제 목표

이름 *: 한 번 4bar 진도와 각 막대기의 기능 (T/SD/D)를 레테르를 붙입니다.

체재는 간단합니다: 4bar 진도에, 그 후에 3개의 기능의 한으로 각 막대기를 레테르를 붙입니다.

초보자 (T 및 D 만)

| C | G | C | C |    T → D → T → T
| C | F | C | C |    T → SD → T → T
| C | F | G | C |    T → SD → D → T

중간 (대용)

| C | Dm | G | C |    T → SD → D → T
| Am | Dm | G | C |    T → SD → D → T
| C | G | Am | F |    T → D → T → SD

고급 (비표준 주문)

| F | G | Em | Am |    SD → D → T → T
| Dm | G | C | Am |    SD → D → T → T
MVP의 범위

차분한 지배자 (V/V, etc.) 및 차분한 합은 Lv4에 범위에서 있습니다. 예를 들어, E7 in "| C | E7 | Am | G |"는 이제 깨끗한 3개의 기능 선택이 끊어지는 것을 포함한 2차 지배자입니다. MVP에서 엄격하게 diatonic 유지.

2개의 층에서 대답 UI 디자인

동일한 정확한 대답을 위해, 제안 2개의 발표 형태. 학습자는 현재 레벨에 맞는 것을 선택합니다.

주요 특징 선택 라벨 관련 기사
초보자 모드 안정 / 개방 / 반품하려는 Lv1–Lv3
이론 모드 T / SD / D Lv4 맨 위로
듀얼 모드 안정적인 (T) / 개구 (SD) / 반품하려는 (D) 전환 단계

이론 모드로 전환은 결코 강제하지 않습니다. 중요한 학습은 감각에 의해 답변 할 수있는 지점에 도달합니다. 라벨은 부산물입니다. 즉, 다른 음악가에게 이야기하는 것은 라벨을 필요로하므로 이동이 deliberately를 권장합니다.

커리큘럼을 넘어

Lv4가 안정되면 다음 테마 레이어가 있습니다. 제안된 순서:

  1. 코드 인식을 구성 - 함수 레벨에서 I / V / IV에서 vi / iii / ii를 구분합니다.
  2. 키 변경 - C 이외의 키에서 동일한 기술을 확인합니다.
  3. 노래방 진행 - I-V-vi-IV, ii-V-I, 그리고 귀에 의한 돌연변이 패턴과 같은 표준을 식별합니다.
  4. 차분한 지배자 & 차분한 코드 — 3개의 기능 구조 밖에서 단계 소리. 여기에서 별도의 기사가 계속됩니다.

5 분 동안 Lv1을 시도하고 기본 라인을 확인

자주 묻는 질문

  1. 한 세션 동안 Lv1을 사용해보십시오. — 기본 설정. "실행"에서 "해결"을 즉시 말해 줄 수 있습니까? 5 분은 충분합니다.
  2. 10-15 분/일, 5 일/주 - 짧은, 자주. Spacing은 학습입니다.
  3. 8/10 점수까지 전하지 마십시오. - 목표가 충족 될 때까지 각 수준에 머물. Lv4를 항상 끊기.
  4. Lv4 : 일찍 토닉 미리보기, 늦은 - 한 번 OFF 작업,이 기술지도는 직접 실제 노래를 transcribing.
  5. 사랑의 노래로 검증 — 당신이 이미 알고있는 4bar chorus에 대한 기능 라벨을 작성. 할 수 있다면, 커리큘럼이 수행됩니다.
